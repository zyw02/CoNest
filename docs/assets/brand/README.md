# CoNest brand assets

The bird emerging from a woven nest represents independent agents sharing a connected environment.

- `conest-logo.svg`: canonical vector mark and wordmark.
- `conest-logo-dark.svg` and `conest-logo-mono.svg`: dark-background and monochrome variants.
- `conest-avatar.svg` / `.png`: square avatar artwork.
- `conest-social-preview.svg` / `.png`: repository social preview artwork.

Use vector sources for rendering; keep raster exports only where the upload surface requires them. Repository asset changes do not update GitHub account avatars or repository social-preview settings automatically. Design proposals and image-generation prompts are kept outside Git.
